# 조사 지시서 — 웹 게임 라이브러리 선정 (2026-09-05)

> 이 문서는 **조사 워커를 위한 지시서**다. 코드를 쓰지 말고 조사와 보고만 한다.

## 만들려는 것

**동물의 숲을 참고한 타이쿤/생활 시뮬레이션 게임.** 자기 공간을 꾸미고, 시간이
흐르고, 자원을 모아 성장하는 종류. 전투 액션이 아니라 배치·수집·성장이 중심이다.

## 실행 환경 제약 (반드시 만족해야 한다)

이 게임은 기존 가계부 앱 안에서 **미니앱**으로 돈다. 아래 제약을 못 지키는
라이브러리는 후보에서 탈락이다.

| 제약 | 내용 |
|---|---|
| 격리 | `<iframe sandbox="allow-scripts">` 안의 **별도 문서**. 부모 DOM·쿠키 접근 불가 |
| 저장 | **localStorage 사용 불가**(sandbox). 부모에게 `postMessage`로 JSON을 넘겨 저장 |
| 배포 | **정적 파일만**. SSR 불가, 서버 런타임 없음. Next.js `output: export` 산출물과 함께 나감 |
| 빌드 | 가능하면 **빌드 스텝 없이** 단일 HTML + `<script src>`. 빌드가 필요하면 그 비용을 명시 |
| 플랫폼 | 모바일 WebView(Capacitor, iOS/Android) 우선. **터치 조작 필수** |
| 크기 | 앱 번들에 함께 실리므로 작을수록 좋다. gzip 크기를 반드시 확인 |

## 조사 항목

### 1. 후보 라이브러리 5~7개

최소 아래를 포함하고, 적합한 것이 더 있으면 추가한다.

- Phaser
- PixiJS
- Kaplay (구 Kaboom.js)
- Excalibur
- melonJS

### 2. 각 후보에 대해

- 최신 안정 버전, 마지막 릴리스 시점, 유지보수 활발도(커밋·이슈 응답)
- **CDN 단일 파일(UMD/IIFE) 제공 여부**와 gzip 크기
- 타일맵 / 아이소메트릭 / 격자 배치 지원 — 동물의 숲류에 필요하다
- 스프라이트·애니메이션·씬 관리
- 모바일 터치·제스처
- 상태 직렬화(세이브) 용이성 — `postMessage`로 넘길 JSON을 만들기 쉬운가
- 라이선스

### 3. 장르 사례

타이쿤·생활 시뮬레이션 장르에 실제로 쓰인 사례가 있으면 링크와 함께.

### 4. 추천

위 제약 아래 **추천 1개와 차선 1개.** 각각 근거와 **포기하는 것**을 함께 적는다.

### 5. 최소 구조 스케치

추천 라이브러리로 만들 때의 파일 구성, 게임 루프, 저장 지점(언제 `postMessage`로
저장하는가), 첫 번째로 만들 수 있는 가장 작은 플레이 가능한 조각.
