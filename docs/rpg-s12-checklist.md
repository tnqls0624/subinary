# 뒷마당 RPG 슬라이스 12 실기기 점검표

2026-09-08 작성. 근거: [설계서 §11의 12일 게이트](redesign-backyard-rpg.md#11-하루-단위-슬라이스--12개). **현재 모든 실기기 항목은 미실행·확인 못 함이다.** iOS와 Android에서 각각 아래 표를 복사해 수행한다. 에뮬레이터·데스크톱 Playwright 결과로 체크하지 않는다. 슬라이스 11 수명 게이트의 상태는 [보고서](rpg-s91011-report.md)를 먼저 확인한다.

## 60Hz 기기에서 60초 산책 성능

각 OS의 **실제 60Hz 기기**에서 지도 로딩을 끝낸 후 60초 연속으로 손가락 산책한다. 측정 중 회전·배경 전환·도감 열기 없이 집 앞→오솔길→연못→그늘을 이동한다. 원격 WebView 검사기의 게임 iframe 실행 문맥에서 아래 측정을 시작하고 원시 `gaps` 결과를 JSON으로 저장한다. 개발용 계측이며 앱에 넣지 않는다. 관찰자가 별도로 영상과 시작·종료 시각을 기록한다.

```js
// 실제 기기의 RAF 간격을 60초간 기록한다. 첫 콜백은 기준점만 만든다.
(() => {
  const gaps = [];
  let start;
  let previous;
  function sample(time) {
    if (start === undefined) start = time;
    if (previous !== undefined) gaps.push(time - previous);
    previous = time;
    if (time - start < 60000) { requestAnimationFrame(sample); return; }
    const sorted = [...gaps].sort((a, b) => a - b);
    const over50 = gaps.filter(gap => gap > 50).length;
    console.log(JSON.stringify({ elapsedMs: time - start, samples: gaps.length,
      p95Ms: sorted[Math.ceil(sorted.length * 0.95) - 1], over50,
      over50Percent: over50 / gaps.length * 100, gaps }));
  }
  requestAnimationFrame(sample);
})();
```

판정: 두 조건 **p95 ≤20ms, 50ms 초과 비율 <1%**를 모두 만족해야 통과다. 표본 기간이 60초 미만이거나 주사율·실기기 여부·실행 문맥이 불명확하면 확인 못 함으로 기록한다. 이는 RAF 프레임 간격 목표이며 GPU 표시 프레임의 직접 측정은 아니다. 원격 검사 연결 여부·발열·절전 상태를 함께 남긴다.

| 기기 | 시간(ms) / 표본 수 | p95(ms) | >50ms 수 / 비율 | 원시 JSON·영상 경로 | 판정 |
|---|---|---|---|---|---|
| iOS | 미기록 | 미기록 | 미기록 | 미기록 | 확인 못 함 |
| Android | 미기록 | 미기록 | 미기록 | 미기록 | 확인 못 함 |

## 첫 90초와 두 사용자 반응

서로 다른 사용자 두 명이 준비된 실기기로 수행한다. 게임 화면이 보이는 순간부터 시간을 재고 “마당을 둘러보세요”만 말한다. 진행 방법을 알려줬다면 개입 시각과 내용을 기록한다. 각 사용자가 **90초 이내 걷기→주민 대화→획득→도감에서 획득 확인**을 순서대로 완료하고 별도 조작 설명이 필요 없으면 통과, 누락·시간 초과는 실패다.

| 기록 | 사용자 A | 사용자 B |
|---|---|---|
| 기기 / 게임 사전 경험 | 미기록 | 미기록 |
| 걷기 / 주민 대화 / 획득 / 도감 확인 시각(초) | 미기록 | 미기록 |
| 관찰자의 개입 / 막힌 지점 | 미기록 | 미기록 |
| 90초 판정 / 영상 | 확인 못 함 | 확인 못 함 |
| “누가 봐도 산책하는 장소인가요?”에 대한 실제 답변 원문 | 미기록 | 미기록 |
| 그렇게 느낀 또는 느끼지 못한 이유 / 자발적 행동 | 미기록 | 미기록 |

산책 장소라는 평가는 두 사람의 원문을 남긴 뒤 각자 긍정/부정/모호로 분류한다. 한 명이라도 부정·모호하거나 답변이 없으면 이 사용자 게이트를 통과 처리하지 않는다. 긍정을 유도하거나 검사자가 답변을 대신 작성하지 않는다.
