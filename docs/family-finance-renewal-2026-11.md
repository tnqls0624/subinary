# 가족 가계부 UI 리뉴얼 — PO 결정 기록

## 문제와 목표

사용자는 설명이 인위적이고 화면이 복잡하다고 했으며, 나만 보기 전역 필터 제거와 자산 자동 추적을 원했다. 이번 리뉴얼은 현재 지원되는 데이터를 더 쉽게 읽고 관리하도록 화면 순서와 문구를 정리한다. 신규 금융사 연결은 이 UI 변경의 완료 조건이 아니다.

- 홈: 등록한 가족 공유 자산과 남은 대출, 이번 달 카드 사용, 다음 주택 납부를 빠르게 확인한다.
- 가계부: 거래를 먼저 보고, 검색하거나 필요한 조건을 열어 찾는다.
- 자산: 현재 기록을 확인하고 필요한 항목만 추가·수정한다.
- 가끔 쓰는 관리 기능은 상단 설정에 둔다. 하단은 홈·가계부·자산 3개를 유지한다.

## 변경 결정

1. 숫자·목록을 관리 기능보다 먼저 배치한다. 신한 파일 가져오기는 자산의 보조 진입으로 둔다.
2. 순자산을 계산할 수 없으면 큰 빈 숫자 대신 확인된 자산·대출 금액을 보여준다. 미입력, 일부 입력, 실제 0원, 조회 실패를 구분한다.
3. 주택 일정이 없을 때 빈 요약과 등록 카드를 중복 표시하지 않는다. 홈의 빈 일정은 간단한 진입으로 줄인다.
4. 가계부는 기간·검색·내역을 기본으로 보여준다. 상세 필터는 접되 적용된 조건과 초기화는 보인다. 분석·예산·검토 상세와 기존 수정 기능은 보존한다.
5. 화면 모드는 설정으로 옮기고, 가족 선택·알림·설정은 헤더에 유지한다.
6. 밝은 청록색을 짙은 청록색으로 바꾸고 흰 카드와 옅은 회색 바탕으로 구분한다. 밝은/어두운 모드의 핵심 본문·버튼 색 대비를 검증한다.
7. 안내는 필요한 위치에서 짧게 설명한다. 출처·기준일·가족 공유·합계 제외 이유와 저장 결과 불명은 숨기지 않는다.

## 유지하는 제품 계약

- 가계부는 카드 승인·취소 중심이다. 전체 수입·이체 장부로 소개하지 않는다.
- 신한 대출은 직접 로그인 후 만든 파일을 사용자가 검토하여 가져온다. 자동 로그인·백그라운드 갱신·실시간 은행 연결을 제공한다고 표시하지 않는다.
- 파일 선택 시 미리보기용 서버 전송 안내, 본인 계좌·금액 확인과 별도의 가족 공유 동의를 유지한다.
- 화면 확인 시각은 은행 잔액 기준일이 아니다. 은행 기준일이 없으면 미확인으로 표시한다.
- 기존 비공개 기록은 설정에서 접근하며 가족 합계에 노출하지 않는다. 전역 필터 제거는 공유 범위 변경이 아니다.
- 주택 계약금액은 자산 시가가 아니다. 남은 납부액은 현금 부족액이 아니다. 실제 납부나 금융 거래를 실행하지 않는다.
- 문자·환율 처리 대기는 사용자가 해결해야 하는 거래와 구분한다.

## 수용 기준과 검증

320/390/1440 화면에서 가로 넘침·잘림이 없고 핵심 행동은 44px 이상 터치 영역을 갖는다. 세 탭, 상세 닫기/뒤로가기, 적용 필터/초기화, 빈/일부 입력/오류/처리 대기, 읽기 전용 사용자, 비공개 기록 비노출, 저장 실패·중복 클릭·늦은 응답을 합성 데이터로 확인한다. 색 대비·관련 단위 검사·타입 검사·모바일 정적 빌드와 브라우저 검증을 최종 소스에 수행한다.

## 작업 및 릴리스 경계

기준 커밋 6ef1b90cb3235fd153b7994304185a78e4461d60의 별도 브랜치 feat/family-finance-renewal에서 작업한다. 직전 미배포 신한 대출 구현과 3탭 변경 67파일을 해시 검증 후 이어받았다. 이번 추가 변경은 프런트엔드와 이 문서이며 기존 API/DB/권한·계산 로직은 변경하지 않는다.

이는 운영 배포가 아니다. 원본 사용자 staged 222개와 유지보수 작업 공간을 보존한다. 배포 시에는 누적 변경과 신한 기능의 0066 테이블 의존성을 별도로 검토해야 한다. 실제 금융사 화면·기기·사용자 데이터로 검증한 것과 합성 UI 검증을 혼동하지 않는다.

## 이후 제품 과제

- 실제 자동 추적: 금융사별 공식 지원·인증·동의·갱신 계약을 먼저 확정한다. 미지원 기관의 연결 버튼이나 자동 갱신 상태를 먼저 만들지 않는다.
- 신한 파일 수집: 실제 은행 DOM과 지원 환경 검증 후 별도 릴리스 판단이 필요하다.
- 사용성: 실제 사용자가 홈에서 잔액을 찾고 가계부에서 특정 거래를 찾는 흐름을 확인한다. 이번 합성 검증은 사용자 조사 결과가 아니다.
