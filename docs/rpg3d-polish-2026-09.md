# 뒷마당 3D 품질 패스 (2026-09-08)

사용자 판정: "그래픽이 조잡하고 아기자기하지 못하다 · 말풍선 방식이 아니다 · 모션이 부자연스럽다 · 게임성이 부족하다."
벤치마크는 ACNH. 이 문서는 **무엇을 왜 바꿨는지**와, 화면을 보며 찾아낸 함정을 남긴다.
검증 방법과 한계는 마지막 절에 있다.

## 1. 진단 — 코드에서 읽은 원인

| 증상 | 원인(코드) |
|---|---|
| 딱딱한 명암 | 툰 그라디언트가 2단(`[140,255]`) |
| 플라스틱 느낌 | 전 캐릭터에 `#4D5C48` 뒤집힌 hull **외곽선**. 벤치마크에는 외곽선이 없다 |
| 떠 보임 | 접지 그림자 없음 |
| 얼룩 잔디 | `sin·cos` 3색 정점색 블롭 |
| 평면적 | **구면 곡률 없음**. 지평선·하늘이 없어 판처럼 보인다 |
| 45° 스냅 회전 | `rotation.y = π/2 − direction·π/4`를 매 프레임 대입 |
| 조각상 같은 정지 | `animate`가 정지 순간 모든 관절을 0으로 스냅, idle 없음 |
| 미끄러지는 걸음 | 걷기 주기 25.6px ÷ 96px/s = **7.5걸음/s**, 다리 회전 0.35rad로 발이 0.04만 움직임 |
| 대화가 게임 같지 않음 | `<dialog showModal>` 중앙 모달 + 배경 어둡게 |

## 2. 바꾼 것

### 장면 (`rpg3d-scene.js`)
- **구면 곡률**: 모든 세계 재질의 vertex shader에 `mvPosition.y -= k·max(0, depth−9)²` 주입(`onBeforeCompile`, `project_vertex` 치환). 그림자 좌표는 `worldPosition`으로 계산되므로 어긋나지 않는다. 하늘 돔·별·달은 굽히지 않는다.
- **시간대**: 0·5·6.5·8.5·16·18·19.5·21·24시 키프레임을 선형 색공간에서 보간. 하늘·태양·반구광·안개·집 창문 emissive·별/달 투명도가 함께 움직인다. 1분마다 갱신. `options.hour`로 고정 가능(미리보기·검증).
- **잔디·길·물**: 캔버스로 그린 64px 텍스처(이미지 파일 0). 물은 UV offset을 흘려 잔물결.
- **나무**: 잎덩이 5개(위가 밝고 아래가 어두움), 인스턴스별 색 변화, 수관 전용 셰이더 바람 흔들림.
- **지평선**: 울타리 밖 풀밭 링 + 낮은 언덕 14개 + 덤불 34개 + 구름 7장 + 밤의 별 220개·달.
- **접지 그림자**: 캐릭터 발밑 radial-gradient 블롭.
- **피드백**: 표본 등장 튀어오름, 획득 반짝이 26입자, 낚시 **찌**(물 안, 낚싯대 끝에서 낚싯줄)와 입질 물결.
- **카메라**: FOV 45→38(원근을 눌러 통통하게), 뒤 10·위 6.4. 대화 중 주민 쪽으로 접근·FOV 34, 세로 화면은 덜 접근하고 시야 반폭에 비례해 오른쪽으로 비켜 선택지 자리를 만든다. 낚시 중 찌 쪽으로 시선을 나눈다.

### 모델·모션 (`rpg3d-models.js`)
- 외곽선 제거. 툰 그라디언트를 8단 선형 램프(바닥 172)로 → **감싸는 조명**.
- 눈 하이라이트·볼 홍조·입 추가. 눈은 눈높이 피벗의 별도 관절이라 깜빡임이 제자리에서 일어난다.
- `animate(rig, distance, moving, delta, pose)`: delta(ms)를 받고 rig의 `motion`에 블렌드·타이머를 둔다.
  - 걷기: 발이 앞뒤로 나가며 앞으로 나가는 발이 들림, 팔 반대 위상, 몸 두 배 주기 바운스·롤, 앞으로 기울임. 주기 44px(플레이어)·30px(주민).
  - 정지: 호흡 0.45Hz, 고개가 가끔 옆을 봄(세제곱으로 가운데에 머묾), 2~4초마다 깜빡임.
  - 말하기: 고개 끄덕임 + 작은 바운스.
  - 정지↔걷기 110ms 지수 블렌드. 앉기·손 뻗기·말하기도 각각 블렌드.
- `face(rig, yaw, delta)`: 최단 호 지수 보간(τ 70ms). **논리 방향은 그대로**고 시각 회전만 부드럽다 — 근접 대상 판정·저장은 바뀌지 않는다.
- 실루엣 계약 유지: 곰 1.4·새 1.2·토끼 최고, 곰 폭 > 토끼 폭, 새 날개 폭 > 곰 폭(`rpg3d-s567.mjs`가 잰다).

### HUD·말풍선 (`backyard-game.tsx`, `.module.css`)
- `<dialog showModal>` → 화면 하단 **말풍선** `section[data-dialogue]`. 이름표(곰 갈색·새 청록·토끼 분홍), ♥ n/12, 한 자씩 타이핑(문장 부호에서 260ms·쉼표 130ms), 끝나면 ▼ 바운스와 선택지. 말풍선 탭 = 타이핑 스킵 / 다음 이야기. 세계는 뒤에서 계속 그려지고 저장 상태도 보인다(설계서 §7). 대화 중 패드·행동 버튼은 숨긴다.
- 보이는 글자는 늘어나지만 요소의 `textContent`는 항상 문장 전체(숨긴 span) — 줄바꿈이 흔들리지 않고 검증도 전체를 읽는다. 스크린리더에는 완성 문장 하나만 따로 알린다.
- 종이색 둥근 버튼 + 아래쪽 두꺼운 그늘, 비네트, 획득 카드 튀어오름 + "처음 만났어요" 배지, 오늘의 할 일 칩(9초 뒤 사라짐), 입질 시 행동 버튼 노란 맥동 + `navigator.vibrate(40)`.

## 3. 화면을 보며 찾은 함정 (다음 사람을 위해)

1. **카메라 상단이 수평선 아래다.** 피치 26.6°·수직 FOV 38°면 화면 상단은 수평선 **−7.6°**. 곡률로 땅은 −18°에서 사라진다. 그래서 "하늘"로 보이는 띠는 −18°~−8°다. 별·달·구름·하늘 그라디언트를 수평선 위에 두면 **전부 화면 밖**이다(220개 점이 그려지는데 하나도 안 보였다). 하늘 요소는 그 띠에 넣어야 한다.
2. **CanvasTexture는 sRGB로 표시해야 한다.** `texture.encoding = THREE.sRGBEncoding`이 없으면 잔디가 크림색으로 바랜다.
3. **InstancedMesh의 `setColorAt`은 재질 색과 곱해진다.** 재질을 흰색으로 두지 않으면 언덕·먼 나무가 검게 나온다.
4. **선형 색공간 lerp는 옅은 쪽으로 치우친다.** 하늘 그라디언트가 파랗게 보이려면 지평선 바로 위에서 천정색에 닿게 지수를 세워야 한다. 돔의 세로 분할이 14°면 보이는 띠 전체가 한 면 안에서 보간된다 — 40분할로 촘촘히.
5. **움직이는 것 위에는 누를 것을 두지 마라.** `transform`(scale·translate) 애니메이션은 바운딩 박스를 흔들어 자동화의 안정성 검사와 사람의 손가락 둘 다 놓치게 한다. `opacity`는 박스를 흔들지 않는다 — **상호작용 요소의 등장은 불투명도로만** 하고, 움직임은 배지·이름표 같은 장식으로 옮긴다. 입질 맥동도 `transform` 대신 `box-shadow`로 바꿨다.
   같은 이유로 `width:max-content` + `translateX(-50%)` 조합은 금물이다 — 안의 글자가 바뀌면 폭이 변하고 재중심되면서 **버튼이 옆으로 밀린다**. 획득 카드는 폭을 고정했다.
6. **카드가 사라지는 것이 정상인 순간이 있다.** 16번째 획득의 완료 ACK에서 규칙이 `card`를 비운다(`rpg3d-world.js`의 `sync`). 위 애니메이션 지연이 겹치면 검증이 "닫기" 버튼을 20초간 다시 찾다 죽는다. `rpg3d-s567.mjs`는 이제 카드가 사라져도 **완료 화면이 열렸으면** 통과하고, 아니면 원래 오류를 그대로 올린다.
7. **하네스는 빌드와 동시에 돌리지 말 것.** SwiftShader 렌더가 빌드와 경합하면 스크린샷이 30초 타임아웃된다.
8. `PointsMaterial`에는 r128에 `fog` 속성이 없다(`setValues` 경고). 점은 원래 안개를 받지 않으므로 무해하지만 경고가 뜬다.

## 4. 검증

- `pnpm --filter web exec vitest run src/lib/game-backyard src/lib/backyard-storage src/lib/miniapp-host` — 14 파일 222개 통과.
- `pnpm --filter web exec tsc --noEmit` — 통과.
- `node scripts/preview-backyard/shot.mjs <out>` — 제품 스크립트를 그대로 로드해 6장면(집 앞·나무 그늘·연못가·오솔길·저녁·밤)×2해상도를 찍는다. 드로우콜 77(폰)/102(가로), 삼각형 9.5만/11.5만.
- `pnpm --filter web build:mobile && node scripts/preview-backyard/route.mjs <out>` — 실제 정적 export의 `/play/app/?key=backyard`를 격리 API fixture로 띄워 입장·말풍선(타이핑 중/완료/다음)·낚시 대기·입질·획득 카드·가로를 찍는다. 운영 API로는 아무것도 보내지 않는다.
- `node scripts/verify-backyard/rpg3d-s567.mjs` — 슬라이스 5·6·7 E2E(주민 실루엣 치수·대화 저장 키·획득 PUT·배치). 말풍선 선택자를 `[data-dialogue][data-open="true"]`로 바꿨다.

**한계**: 전부 데스크톱 Chromium(SwiftShader) 결과다. 실기기 프레임·터치·회전은 슬라이스 8로 남아 있다. 시간대는 기기 시각을 따르므로 사용자가 보는 화면은 시각에 따라 다르다 — 밤에 처음 열면 어두운 마당이 정상이다.
