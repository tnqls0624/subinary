## 2. 벤치마크에서 가져오는 것

토스·뱅크샐러드·카카오뱅크·편한가계부·Monarch·Copilot·YNAB·Rocket Money·Honeydue를 조사했다(공식 도움말·디자인 시스템 문서·분석 기사 기준, 직접 설치는 하지 않음).

| 원칙 | 출처 | 고치는 불만 |
|---|---|---|
| 상태는 **띄워 두고 묻지 않는다** — "3분 전" 같은 메타 + 문제 있을 때만 칩. 상태 확인 버튼 없음 | Copilot, Monarch | C3, C1 |
| 문제 있는 연결만 자산 탭 맨 위에 모으고, 정상이면 섹션 자체를 숨긴다 | Copilot | C3 |
| '추가'는 헤더 버튼 하나 → **바텀시트**에서 자동/직접 선택 | Rocket Money, 뱅크샐러드 | C2 |
| 지원 안 되는 기관은 목록의 비활성 행 + `준비 중` 칩으로 **시작 전에** 알린다 | 토스 | C1 |
| 시트 제목 한 줄, 설명 최대 한 문장, 긴 설명은 `자세히`로 | 토스 UX 라이팅 | C1 |
| 버튼은 **채움(주) / 옅음(보조) / 텍스트** 3단계, 화면당 채움 1개 | 토스 TDS | C4, C5 |
| 금액 색은 의미로 고정, 숫자는 tabular, 화면당 대표 숫자 하나 | Copilot | C5 |
| 소유는 항목의 작은 칩, 시점 전환은 상단 필터 하나 | Monarch, Honeydue | C1 |

**피한다**: 상태를 묻는 버튼, 텍스트 없는 아이콘 단독 상태, 마지막 동기화 시각 없는 "정상" 표시, 위험·오류 정보까지 지우는 과잉 단순화(토스 '외상' 사례 — 우리 계약의 "제외 이유를 숨기지 않는다"와 같은 원칙).

## 3. 디자인 시스템

새 규칙은 `globals.css` 토큰과 `components/ui`, `components/widgets`에만 둔다. 화면은 이것만 조합한다.

### 3.1 타이포 — 6단계

| 토큰 | 크기/행간 | 용도 |
|---|---|---|
| `display` | 28/34 bold, tabular | 화면당 대표 금액 1개 |
| `title` | 22/28 bold | 화면 제목 |
| `heading` | 17/24 semibold | 섹션·카드 제목 |
| `body` | 15/22 | 본문, 목록 주 텍스트, 금액 |
| `caption` | 13/18 | 보조 정보(카드·날짜·상태 메타) |
| `micro` | 11/14 | 칩·배지 |

임의 값(`text-[13px]` 등)은 lint로 금지한다.

### 3.2 모양

- 모서리: `card 16` · `control 12` · `full`(칩·아바타) 3종.
- 카드 구분은 테두리 대신 배경 톤(본문 `muted` 위에 `card`). 카드 안 구획은 여백으로 나누고 구분선은 목록 행 사이에만.
- 간격: 4의 배수, 화면 좌우 20, 섹션 사이 28, 카드 내부 20.

### 3.3 버튼

| 종류 | 모양 | 규칙 |
|---|---|---|
| 주(fill) | primary 채움, 높이 52, 화면 하단 고정 또는 섹션 끝 | **화면당 1개** |
| 보조(weak) | primary 10% 배경 + primary 글자 | 주 행동 옆이나 카드 안 |
| 텍스트 | 글자만 | `더보기`, `전체 보기`, 시트의 `닫기` |
| 아이콘 | **배경 없음**, 아이콘 24 + 터치 44 | 헤더·행 끝. 활성은 아이콘 색만 바꾼다 |
| 위험 | 텍스트 버튼 + destructive 색 | `연결 해제`, `삭제`. ⋯ 메뉴 안에만 |

`tint`·`outline`·`secondary` 변형은 위 3종으로 흡수하고 삭제한다.

### 3.4 공용 컴포넌트 (신설·정리)

`ListRow`(아이콘·제목·메타·값·화살표), `StatusChip`(정상/주의/오류/준비 중 + 짧은 텍스트), `Amount`(원화·외화 자릿수 규칙, 부호 색), `SectionHeader`(제목 + 오른쪽 텍스트 버튼), `BottomSheet`(제목 한 줄 + 선택지), `OverflowMenu`(⋯).

### 3.5 문구 규칙

1. 한 덩어리 설명은 **한 문장**까지. 두 번째 문장이 필요하면 `자세히`(시트)로 보낸다.
2. 상태는 문장 대신 칩 + 메타: `연결됨 · 3분 전`, `확인 필요`, `준비 중`.
3. 버튼은 동사형 짧게: `조회하기`, `추가하기`, `닫기`. 보조 버튼에 `취소` 대신 `닫기`.
4. 내부 용어 금지: Codex, 실행기, 파서, 환율 확보, 원문, 처리 상태, 기준 시각.
5. **계약 문구는 줄이되 지우지 않는다**: 합계 제외 이유, 미확인 기준일, 비공개 미노출은 칩/한 줄로 남긴다.

## 4. 구조(IA)

**하단 탭 4개: 홈 · 가계부 · 자산 · 전체** (ADR-0037, 2026-11-04 결정). 헤더는 `모아 · 가족 전환 · 알림`만 남고 설정 톱니바퀴는 사라진다.

- `전체` = 기존 `/more`. 설정 아래 화면(`ACCOUNT_PATHS`)에 있는 동안 `전체` 탭이 활성이다 — 헤더 아이콘의 채움 박스 활성 표시는 없어진다.
- 재학습은 이번 한 번으로 묶는다(R2~R6 동시 배포).
- 자산 탭: '자산 관리'(주택 납부·결제 카드) 묶음을 자산 목록의 행으로 흡수.
- 자동 연결: 설정 → 자동 연결은 유지하되, 자산 탭에서 바로 연결 상세로 들어간다(진입점 2개로 정리: 자산 추가 시트, 연결 계좌 행).

## 5. 화면별 개편안

### 홈
1. **이번 달 카드 사용액**(display) + 월 스위처 + 지난달 대비 한 줄. 처리 대기는 숫자 밑 회색 상태 문구(`문자 N건을 거래에 반영하는 중이에요`, 누르지 않음). 환율이 없어 멈춘 문자만 할 일로 가는 줄. *(2026-11-05: '확인 대기' 칩은 사용자가 확인해야 한다고 읽혀 바꿨다)*
2. 할 일 카드(있을 때만): `확인할 거래 1건` 행.
3. 예산 진행 요약: 예산별 한 줄 막대(최대 3개) + `전체 보기`.
4. 주택 납부: 다음 일정 한 줄. 없으면 카드 숨김.
5. 자산 요약 한 줄 행: `남은 대출 111,440,000원 · 자산 미입력` → 자산 탭. (큰 남색 카드 제거)

### 가계부 — 거래
- 행: 가맹점(body) / `카드 · 사람 · 카테고리`(caption) / 금액. **`승인` 배지 제거**(기본 상태는 표시 안 함), 취소·실패만 칩.
- 일시불이면 할부 표시 없음(결함 수정).
- 날짜 그룹 머리: `11월 3일` + 오른쪽 소계. "원화 승인 소계" 문구 제거.
- `거래 추가`는 헤더 아이콘 버튼(+).

### 가계부 — 분석 · 예산 · 할 일
- 분석: 대표 숫자 1개, 승인/취소/건수 박스 → caption 한 줄. `이 달의 특징 보기`는 텍스트 버튼.
- 예산: 카드마다 `사용 / 한도` + 막대 + `남은 금액`만. 카드 구성(`네이버 현대카드 · 소유자 이수빈 · •••• 9908` 칩 나열)은 ⋯ → 상세로. `예산 만들기`는 헤더 + 버튼.
- 할 일: 섹션 설명 문단 제거. 문자 묶음은 `카드사 이름 · 1건`으로(발신번호 대신), 처리 대기(환율 등)는 별도 섹션이 아니라 `대기 중` 칩이 붙은 행. *(2026-11-06: §8 '할 일 화면'으로 바뀜)*

### 자산
1. 헤더: `자산` + 오른쪽 + 버튼 → **바텀시트** `자산 추가`: `은행·증권 연결`(신한은행·토스증권) / `직접 입력`.
2. (문제 있을 때만) `확인이 필요한 연결` 섹션: `신한은행 · Mac 꺼짐` 행 → 연결 상세.
3. 순자산 요약: 대표 숫자 1개. 계산 불가면 `계산 전 · 자산 금액 미입력` 칩(계약: 미확인 표시 유지).
4. 목록: 종류 필터 칩 + `ListRow`. 연결 계좌는 같은 목록에 섞되 `내 연결 · 3분 전` 메타와 `합계 제외` 칩.
5. 외화: `$10,294.66`(소수 2자리), 원화 환산 안 함은 칩 `환산 안 함`.

### 자동 연결 (설정 → 자동 연결, 자산에서 진입)
- 첫 화면은 **기관 목록** 한 장: `신한은행  연결됨 · 3분 전 ›` / `토스증권  준비 중` / `국민은행  준비 중`(비활성).
- 신한 상세:
  - 상단 상태 한 줄 `Mac 연결됨 · 마지막 조회 11/3 21:17` (상태 확인 버튼 없음 — 화면 진입 시 자동 갱신, 당겨서 새로고침).
  - 결과: 통장 잔액, 대출 원금(기존 `ListRow`).
  - 주 버튼 1개 `지금 조회하기`.
  - ⋯ 메뉴: `로그인 정보 변경` · `연결 해제`(위험).
  - 동의·보관 안내는 로그인 정보 입력 시트 안에서 한 문장 + 체크 + `자세히`.
- 처음 연결할 때만 단계형 시트: 1) Mac 연결 2) 로그인 정보 3) 첫 조회.

### 설정
- 프로필 카드 → 한 줄 행(이름 · 이메일). 검색창 제거(항목 12개에 검색은 과함).
- 아이콘은 배경 원 없이 24px. 그룹: `가족·연결` / `알림·화면` / `계정`. `상세 설정` 접힘 해제하고 그룹에 편입.

## 7. 결정 (2026-11-04, 소유자 확인)

1. **하단 탭 4개**(`홈·가계부·자산·전체`)로 간다. 설정을 탭으로 올리고 헤더 톱니바퀴를 없앤다 → ADR-0037.
2. **'승인' 배지 제거**: 기본 상태는 표시하지 않고 취소·실패만 칩으로 보여준다.
3. **신한 연결은 사용자 화면에 유지**하고 Mac 의존은 상태 한 줄(`Mac 연결됨 · 3분 전`) + 주 버튼 하나로 줄인다. 처음 연결할 때만 단계형 안내.
