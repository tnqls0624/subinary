# Phaser 4.2.1 타입 선언

`phaser.d.ts`와 `matter.d.ts`는 고정 UMD와 동일한 npm `phaser@4.2.1` 배포물의 원본이다.

- https://cdn.jsdelivr.net/npm/phaser@4.2.1/types/phaser.d.ts
- https://cdn.jsdelivr.net/npm/phaser@4.2.1/types/matter.d.ts
- 라이선스: `../../public/miniapps/vendor/PHASER-LICENSE.md`

배포 선언의 `any`는 upstream 원본이며 수정하지 않았다. 제품의 신규 어댑터·입력·규칙에는 `any`를 사용하지 않는다. 선언은 public 바깥에 두어 OTA에 넣지 않고, 순수 규칙 검사에는 포함하지 않는다.
